# Версия 2.0 — запуск красивой панели в Telegram

Это обновление существующего бота. Оно включает Telegram Mini App с тремя темами: светлая, тёмная и «Уютная дача». Панель работает на основе согласованных макетов: крупные карточки избранного, заметные переключатели, смена дома сверху. Для устройств используются встроенные векторные иллюстрации; фотографии из эскизов не являются фотографиями ваших приборов.

## Что будет доступно

- Главная: избранные устройства выбранного дома, крупные кнопки включения/выключения, звезда на карточке.
- Все устройства: свет и добавленные вами розетки/выключатели.
- Комнаты: свет по комнатам выбранного дома.
- Карточка устройства: нажмите название для яркости, температуры белого и RGB-цветов, если эти функции доступны через API.
- Настройки: три темы, личный переключатель уведомлений и добавление розеток/выключателей в свет.
- Тема, избранное, дом и уведомления сохраняются для каждого Telegram ID. Добавленные розетки/выключатели — общие для пользователей, как в версии 1.3.
- Текстовое меню и полная диагностика из версии 1.3 продолжают работать.

## Обновление на bothost.ru

На этот раз недостаточно заменить только bot.py: появились сервер, веб-файлы и зависимость aiohttp.

1. Остановите текущий бот. Сохраните резервную копию /app/data/bot.sqlite3 и прежние переменные окружения.
2. Загрузите все файлы нового архива в корень проекта либо обновите репозиторий. В корне должны быть bot.py, core.py, mini_app.py, requirements.txt и Dockerfile. Папка web должна находиться рядом с bot.py. Не загружайте тестовые/чужие базы вместо вашей.
3. Сохраните TELEGRAM_BOT_TOKEN, YANDEX_OAUTH_TOKEN, ALLOWED_USER_IDS, EXTRA_LIGHT_IDS и прочие ваши настройки. Обязательно оставьте DATA_DIR=/app/data.
4. Включите домен для этого проекта в панели Bothost. Используйте предоставленный HTTPS-поддомен или свой HTTPS-домен. Точные названия экранов зависят от интерфейса и тарифа Bothost.
5. Установите порт проекта 8000. Переменная PORT тоже должна быть 8000. Приложение само слушает 0.0.0.0; HTTPS завершается на стороне прокси Bothost.
6. Добавьте переменную WEBAPP_URL со своим адресом, например:

   WEBAPP_URL=https://my-home.bothost.tech
   PORT=8000
   DATA_DIR=/app/data

   Это пример: вставьте именно адрес вашего проекта. URL должен начинаться с https://, без дополнительных путей, параметров и секретов. Если домен ещё не подключён, оставьте WEBAPP_URL пустым — текстовый бот продолжит работать, но кнопки панели не будет.

7. Пересоберите контейнер с новым requirements.txt. В архиве есть Dockerfile, запускающий и бот, и веб-сервер одной командой python bot.py.
8. Запустите только один экземпляр для вашего Telegram-токена.
9. Для проверки сервера откройте https://ВАШ-ДОМЕН/health — должен вернуться {"ok": true}. Это только проверка доступности сервера, без доступа к устройствам.
10. В Telegram отправьте /start и нажмите «🏠 Открыть панель». Также бот устанавливает кнопку меню «🏠 Мой дом».

## Первый запуск панели

1. Выберите «Дача» сверху.
2. Настройки → Устройства света → добавьте «Розетка торшер», «Прожектор Андрея», нужные гирлянды. Добавление в список не подаёт питание.
3. Откройте Главная → Все устройства → отметьте звёздами нужные карточки.
4. Вернитесь на Главную: избранное будет сразу перед вами.
5. Настройки → Оформление → выберите светлую, тёмную или «Уютную дачу». По умолчанию используется тёмная.
6. Проверьте включение одной лампы, затем выключение. Проверьте второй дом и второго пользователя.

## Доступ и сохранение

Панель принимает только подписанные Telegram данные initData. Подпись проверяется сервером через токен бота, затем проверяются время авторизации (до одного часа) и текущий ALLOWED_USER_IDS. Присланный из браузера произвольный Telegram ID прав не даёт. Внешняя ссылка без запуска из Telegram показывает только экран входа, без устройств и команд.

Токен Яндекса и токен бота не передаются браузеру. initData хранится только в памяти открытой страницы и передаётся серверу в заголовке, не в URL. Не отправляйте кому-либо содержимое этого заголовка или дампы сетевых запросов.

Если открытая панель сообщает, что авторизация устарела, закройте её и откройте заново кнопкой бота. После изменения белого списка на хостинге перезапустите бот.

Избранное и настройки берутся из прежней SQLite. При первом старте добавляется таблица оформления; остальные данные не перезаписываются.

## Состояние и команды

Кнопка ↻ обновляет список. Пока панель открыта, список автоматически запрашивается раз в минуту. API Яндекса может отдавать состояние с задержкой, поэтому успешная команда подтверждается ответом action_result, затем бот читает состояние повторно.

Во время команды кнопки блокируются. При сетевом таймауте не повторяйте команду вслепую: сначала обновите состояние. POST-команды в API Яндекса автоматически не повторяются. Сервер дополнительно запоминает последние 500 идентификаторов команд, включая ошибки с неизвестным результатом; эта защита работает до перезапуска процесса или вытеснения старого идентификатора.

## Если не открывается

- Нет кнопки панели: проверьте WEBAPP_URL, перезапуск и отправьте /start снова.
- HTTPS-адрес даёт 502/504: проверьте совпадение PORT и порта в панели Bothost, успешную сборку контейнера, наличие mini_app.py и папки web.
- Панель просит открыть её из бота: используйте именно web_app-кнопку в личном чате, а не внешний браузер и не обычную ссылку.
- Доступ закрыт: проверьте числовой Telegram ID в ALLOWED_USER_IDS.
- Пустое избранное: отметьте устройства звёздочкой на странице «Все устройства».
- Нет света на даче: добавьте розетки и выключатели в настройках панели.
- Нет иллюстраций/не загружается интерфейс: убедитесь, что скопирована вся папка web и обновлён Dockerfile.
- Старый текстовый бот всё ещё работает, но панели нет: обновите весь проект, а не один файл.

## Проверки сборки

39 автоматических тестов: прежние функции, подпись/срок initData, запрет посторонним и отозванным пользователям, изоляция домов, личные темы и избранное, команды и защита от дублей, добавление розеток, отдача статики без раскрытия исходников/конфигурации.

Дополнительно проверены синтаксис JavaScript и Python, файлы SVG и ZIP. Автоматизированная визуальная проверка в браузере и реальный запуск в вашем Telegram/Bothost не выполнялись. Для завершения подключения нужны ваши настройки домена и токены в хостинге — в переписку их присылать не нужно.
